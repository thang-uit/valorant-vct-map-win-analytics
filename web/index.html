WHAT THIS IS

A film-room instrument,
not a live oracle.

Each point on the chart is generated after a round has finished. The model receives the round history, current score, economy state, map and five-agent compositions, then estimates whether Team A will eventually win the map.

The web page is a static post-match simulation. It does not watch a live game, recommend purchases, or claim that an agent caused a win. Its practical use is to help an analyst find turning points worth revisiting in a VOD.
